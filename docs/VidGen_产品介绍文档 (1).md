## 1. 项目背景

过去三年，电商商家、品牌方和内容创作者面对同一个困境：投流成本越来越高，但有效内容供给跟不上。一条爆款短视频背后通常需要 3—7 人的团队、5—10 天的制作周期、上万元的成本。爆款不可复制的本质不是缺创意，而是缺产能。

行业现有工具都只解决了某一个局部环节，没有形成闭环。

| 工具类型 | 代表产品 | 局限 |
|---------|---------|------|
| 传统剪辑软件 | 剪映、Premiere | 全链路依赖人工，单条视频 4—8 小时 |
| 单镜头 AI 生成 | Sora、Runway、可灵 | 只能生成单镜头，不解决端到端编排 |
| AI 编辑工具 | CapCut Pro、Falcocut | 解决片段级问题，不解决全流程 |
| 原生 ComfyUI 工作流 | — | 节点需人工配置，无法自动决策 |

VidGen 的判断是：**营销视频生产的瓶颈不在生成模型本身，而在策划、分镜、合成、投放、回看这五个环节之间的协同。这是一个 Agent 编排问题，不是模型问题。**

VidGen 不与 Sora 这类单镜头视频生成模型竞争，而是把它们作为底层工具，在上层用多 Agent 协作的方式编排成端到端的内容生产流水线。同时通过流量回看 Agent 形成数据闭环，让系统越用越懂用户的爆款公式。

## 3. 主要适用场景及案例

### 场景一：电商新品上市投流测试

**背景**：杭州蓝牙耳机品牌，月销 3000 单，月度广告预算 50 万元。新品上市需要快速测试不同卖点和创意方向，找到 ROI 最高的投流素材。

**痛点**：传统流程需要 1 周准备 1 条素材，无法做规模化 A/B 测试，错过新品上市黄金窗口。

**VidGen 解法**：粘贴一条同行爆款 URL，一晚上跑出 10 条同款风格但不同卖点的衍生视频，第二天直接投放，3 天内拿到流量数据反馈，第 4 天聚焦表现最好的方向继续放量。

**效果**：单条素材成本从 3000 元降至 100 元以内，素材产能从每周 1 条提升至每天 10 条。

### 场景二：MCN 矩阵账号同款复刻

**背景**：MCN 运营 30 个垂类账号，每个账号每周需要发 5 条原创视频。

**痛点**：30 × 5 = 150 条/周的内容产能，靠人力完全不可能完成。复用素材会触发平台限流。

**VidGen 解法**：每个账号绑定一个风格 LoRA，给定本周内容主题后，VidGen 基于历史爆款结构自动生成同风格但不同内容的视频。每条视频的脚本结构、镜头节奏由系统针对账号定位独立优化。

**效果**：30 个账号的内容生产从需要 30 个剪辑师变成 1 个运营 + VidGen，单账号月成本下降 80% 以上。

### 场景三：跨境电商多语言素材生产

**背景**：跨境电商品牌投放 TikTok 全球市场，需要中、英、西、阿四语种素材。

**痛点**：找四种语言的母语创作者成本极高，且素材风格不统一。

**VidGen 解法**：一份脚本通过 VidGen 生成四语种版本，TTS 配音 + 字幕对齐自动完成，视觉部分共用同一份镜头资产，仅替换文案和配音。

**效果**：四语种素材在同一天产出，风格统一，成本相比传统方式下降 70%。

## 4. 功能总览

**一句话描述闭环链路**：用户输入一条爆款视频 URL 和产品信息，VidGen 通过"爆款解析 → 脚本策略 → 分镜生成 → 视频生成 → 智能合成 → 质量检测 → 流量回看"七个 Agent 接力协作，自动产出营销视频，并把投放后的流量数据沉淀为下一轮生成的优化依据。

链路中的功能模块：

| 序号 | 模块 | 一句话职能 |
|-----|------|-----------|
| M1 | 爆款解析 | 把参考视频结构化为可学习的特征 |
| M2 | 脚本策略 | 基于特征和产品信息生成结构化脚本 |
| M3 | 分镜生成 | 把脚本切成可生成的镜头清单并选择技术路径 |
| M4 | 视频生成 | 调度 ComfyUI 工作流批量产出镜头片段 |
| M5 | 智能合成 | 配音、字幕、BGM、转场合成成片 |
| M6 | 质量检测 | 多维度自动 QA，失败自动回退或转人工 |
| M7 | 流量回看 | 追踪投放数据，沉淀爆款经验反哺下一轮 |

七个模块通过共享 GraphState 协作，所有中间产物可见、可恢复、可回看。

## 5. 页面与功能说明

VidGen 的核心使用闭环从用户登录开始，按时间顺序经过以下页面与模块。每个模块独立可用，也可作为 API 被外部系统集成。

本节中：

- **主要功能**：说明这个页面能做什么。
- **用户价值**：说明用户为什么需要这个页面。

### 5.1 登录页

**一句话描述**：用户身份验证入口，支持手机号、邮箱、企业微信 SSO 三种登录方式。

**主要功能**：

- 让用户通过手机号验证码、邮箱密码或企业 SSO 完成登录。
- 让新用户完成注册，并在首次登录后进入工作台。
- 让受邀成员通过团队邀请链接加入对应组织。
- 让系统建立用户会话，识别用户身份、团队归属和内部资源配额。
- 让用户退出登录或在会话过期后重新认证。

**重点功能说明**：登录态采用 JWT + Refresh Token 双 Token 机制，Access Token 有效期 2 小时，Refresh Token 有效期 30 天。企业版支持 SAML 2.0 单点登录。

**用户价值**：用户需要这个页面，是因为 VidGen 的项目、素材、内部配额、历史任务和发布账号都需要绑定到明确身份。登录页保证用户可以安全进入自己的工作空间，也让团队协作、权限隔离和历史资产沉淀成为可能。

### 5.2 工作台首页

**一句话描述**：用户登录后的主入口，展示内部配额、最近任务、爆款灵感推荐三大模块。

**主要功能**：

- 展示团队/个人内部配额、本月使用量和剩余生成次数。
- 展示最近任务状态，让用户快速回到生成中、已完成或失败可重试的任务。
- 展示按行业或账号偏好推荐的爆款灵感内容。
- 提供创建新任务、进入素材库、查看历史项目和管理账户的入口。
- 汇总用户当前最需要关注的待处理事项，例如待确认分镜、失败重试或待发布成片。

**重点功能说明**：爆款灵感推荐流基于用户绑定的行业标签，每天 0 点更新一次，数据来源是用户授权的平台 API + VidGen 自有的爆款监控池。

**用户价值**：用户需要这个页面，是因为它把“我现在还有多少内部资源配额、哪些任务在跑、哪些结果要处理、下一条视频从哪里开始”集中到一个入口。用户不必在多个页面之间寻找状态和灵感，可以更快进入创作或运营动作。

### 5.3 创建任务页

**一句话描述**：用户填写产品信息和参考视频，提交生成任务的核心入口。

**主要功能**：

- 让用户输入参考视频 URL 或上传本地视频作为复刻对象。
- 让用户填写产品名、卖点、目标人群、目标平台、目标时长等任务信息。
- 让用户选择语种、情绪、品牌色、风格偏好和是否使用品牌 LoRA。
- 让用户配置变体数量、随机种子、是否开启人工镜头确认等高级选项。
- 在提交前展示预估耗时、预计镜头数和内部资源消耗。
- 将用户输入整理成可被 Agent 流水线执行的结构化任务。

**重点功能说明**：URL 粘贴后自动触发轻量级解析（5 秒内返回视频时长、镜头数预估），让用户在提交前就知道"这条参考视频会生成多少镜头、大概要等多久"。

**用户价值**：用户需要这个页面，是因为它把“想做什么视频”转换成系统可以执行的明确任务。用户不用理解 Agent、模型和剪辑流程，只需要提供参考、产品和目标，系统就能开始生成。

### 5.4 任务进度页

**一句话描述**：实时展示当前任务在七个 Agent 中的执行进度，用户可观察、介入、终止。

**主要功能**：

- 实时展示爆款解析、脚本策略、分镜生成、视频生成、智能合成、质量检测、流量回看等节点状态。
- 让用户查看每个节点的输入、输出、中间产物、耗时和 Token 消耗。
- 在需要人工确认时展示分镜或复刻方案，并允许用户批准、修改或拒绝。
- 在失败或 QA 回退时展示失败节点、原因、回退路径和重试次数。
- 提供暂停、终止、重试、复制配置生成新任务等任务级操作。

**重点功能说明**：进度页基于 WebSocket 推送，无需用户刷新即可实时更新。每个节点的中间产物（参考视频分析报告、脚本草稿、分镜列表、镜头预览）都可单独下载查看。

**用户价值**：用户需要这个页面，是因为视频生成是一个长流程任务，用户必须知道任务跑到哪里、是否需要自己确认、失败后该怎么处理。进度页把 AI 黑盒变成可观察、可干预、可恢复的生产过程。

### 5.5 视频预览与编辑页

**一句话描述**：任务完成后展示成片，支持镜头级编辑和导出。

**主要功能**：

- 播放任务生成的成片，并在时间轴上标记每个镜头。
- 让用户对单个镜头进行重生成、替换、删除或顺序调整。
- 让用户编辑字幕、旁白文案和配音，并重新合成对应片段。
- 支持同一任务的多个版本并排预览和对比。
- 支持按平台规格导出竖版、横版或方版视频。
- 在用户完成平台授权后，支持将成片发布到绑定账号。

**重点功能说明**：镜头级重生成不会重跑整个流水线，只重新执行 GenerationAgent 中的对应镜头节点，平均耗时 90 秒。

**用户价值**：用户需要这个页面，是因为 AI 生成的结果通常还需要最后确认和精修。预览与编辑页让用户保留对成片质量、镜头细节、字幕表达和发布版本的控制权，而不用重新跑完整流程。

### 5.6 流量回看页

**一句话描述**：已发布视频的流量数据看板，自动归因表现好坏的原因。

**主要功能**：

- 展示已发布视频在 24 小时、72 小时、7 天等时间窗口内的表现。
- 展示播放量、完播率、互动率、转化率、CPM 等核心指标。
- 将当前视频与同账号历史视频进行横向对比和排名。
- 基于脚本结构、视觉风格、镜头节奏和 CTA 等特征生成归因报告。
- 将表现优秀的视频标记为爆款样本，并沉淀到下一轮生成的参考池。

**重点功能说明**：流量回看不是简单展示数据。系统会基于结构化的脚本特征做因子归因，告诉用户"这条视频的钩子位置（前 1.5 秒）+ 中等节奏 + 强 CTA"是它表现好的关键，下一轮生成会优先采用这个组合。

**用户价值**：用户需要这个页面，是因为营销视频不是生成完就结束，真正重要的是知道哪条内容有效以及为什么有效。流量回看页把投放结果变成下一轮生成的策略依据，让用户持续优化爆款公式。

### 5.7 素材库与项目管理

**一句话描述**：用户上传的产品素材、品牌资产、历史项目的统一管理空间。

**主要功能**：

- 让用户上传、查看和管理产品图、产品视频、品牌 Logo、人物素材和 BGM 音轨。
- 让用户按项目、产品、平台、时间、标签或表现状态筛选素材和历史任务。
- 让用户把多个相关任务组织到同一个项目空间中。
- 让团队成员在同一项目下共享素材、查看任务和复用历史产物。
- 让用户管理品牌风格资产，例如专属 LoRA、爆款模板和可复用配置。

**重点功能说明**：LoRA 训练在云端完成，用户无需 GPU。训练数据 50—200 张图片即可，单次训练耗时 15—30 分钟，训练完成后可在所有后续任务中调用。

**用户价值**：用户需要这个页面，是因为持续生产视频会积累大量素材、项目和历史结果。素材库与项目管理页把一次性上传变成长期资产沉淀，让用户能复用品牌资产、减少重复整理、提升团队协作效率。

### 5.8 团队与权限中心

**一句话描述**：企业内部成员管理、权限分配、用量查看和 API Key 管理入口。

**主要功能**：

- 让管理员邀请成员加入团队，并分配管理员、编辑、审核、查看等角色。
- 让团队共享内部资源配额，并查看团队/成员用量情况。
- 让管理员按团队、成员或项目查看资源消耗和操作记录。
- 让开发者创建、停用和管理 API Key。
- 让企业为不同成员或 Key 设置权限、内部配额上限和调用频次限制。

**重点功能说明**：API Key 支持按 Key 设置内部配额上限和调用频次限制，便于企业把 VidGen 集成到自己的内部系统时做精细化控制。

**用户价值**：用户需要这个页面，是因为企业内部使用 VidGen 时不只是个人创作，还涉及成员协作、权限控制、资源消耗归因和系统集成。团队与权限中心让管理者可以安全地把 VidGen 分发给多人使用，并控制内部资源和权限边界。

## 6. 核心能力

VidGen 的核心能力是其他工具不具备的差异化价值。

### 6.1 端到端 Agent 编排

七个 Agent 通过 LangGraph StateGraph 协作，全链路无人工介入。所有 Agent 共享一个 GraphState 对象，状态可观测、可序列化、可回放。这是 VidGen 与"单镜头视频生成模型 + 人工拼接"模式的根本区别。

### 6.2 爆款结构化复刻

不是简单的"换脸 + 文字替换"。VidGen 的爆款解析模块会把参考视频拆解为可学习的结构化特征：钩子位置、节奏类型、镜头数量、镜头时长分布、风格关键词、字幕样式、BGM 风格。脚本生成时这些特征作为 few-shot 上下文注入，确保生成视频在"骨架层面"与爆款对齐。

### 6.3 数据闭环：流量回看反哺生成

每条已发布视频的流量数据通过 AnalyticsAgent 回流，与脚本结构特征关联存入 Qdrant 向量库。下一轮生成时自动检索 top-3 高表现历史案例作为 few-shot context。系统越用越懂用户的爆款公式。

### 6.4 工程化的失败恢复

每个 Agent 节点入口和出口写 Checkpoint 到 Redis。任务失败可从最近的 Checkpoint 续跑，已生成的镜头不重复消耗算力。QA 失败按失败原因路由到对应上游节点（视觉问题回到生成层、时长问题回到分镜层、音频问题回到合成层），重试 3 次仍失败升级为人工审核。

### 6.5 显存友好的部署能力

复用作者在小影实习期间验证的工程优化策略：模型按需加载 + 动态卸载、FP16 推理、视频帧流式处理。单卡 L20（90 GiB RAM）即可承载完整推理链路，相比业内同类方案降低 30% 部署成本。

### 6.6 多入口接入

Web 工作台覆盖普通用户，REST API 覆盖开发者和企业系统集成，MCP Server 覆盖 Agent 生态。同一套底层能力通过三种入口暴露，用户在哪个生态都能用上 VidGen。

### 6.7 镜头级精修

用户拿到 AI 生成的成片后，可以对任意单个镜头做重生成、替换、删除，无需重跑整个流水线。这让 VidGen 既保持了 AI 自动化的效率，又给用户保留了对最终质量的控制权。

## 7. 使用流程示例

### 完整使用流程：张老板的一天

> **角色背景**：张老板，杭州蓝牙耳机品牌主理人，月度广告预算 50 万元。
> **任务目标**：为新款降噪耳机准备 10 条投流素材，3 天内完成测试投放。

**Day 1 上午 9:00 — 灵感搜索**

张老板登录 VidGen 工作台。首页"爆款灵感推荐流"显示了过去 24 小时数码/3C 类目下的 30 条高表现视频。他选中其中一条 500 万播放的同行爆款，点击"用此视频作为参考"。

**9:05 — 创建任务**

系统跳转到创建任务页，参考视频字段已自动填好。张老板填写：

- 产品名：XX 主动降噪蓝牙耳机
- 卖点：50dB 主动降噪、续航 40 小时、单耳 3.5g
- 目标平台：抖音 + TikTok
